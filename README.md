# Aetherphone Beta

The testing channel for [Aetherphone](https://github.com/XeldarAlz/FFXIV-Aetherphone). Builds come straight off the
plugin's `dev` branch, ahead of the stable release. This repository holds no source code; it serves the beta builds
to Dalamud.

## Install

1. In game, open **Dalamud Settings** (`/xlsettings`), go to **Experimental**, and add
   `https://aetherphone.net/beta/repo.json` to **Custom Plugin Repositories**.
2. Install **Aetherphone Beta** from the **Plugin Installer**.

The beta installs next to the stable plugin with its own settings, opens with `/phonebeta`, and signs in to the
Aethernet test server (switch it under **Settings, About**).

## Version numbers

A beta carries the version it previews plus its build number: **1.3.1.3** is beta 3 of 1.3.1.0, which **Settings,
About** shows as "1.3.1.0 beta 3".

## Reporting

Report bugs in [FFXIV-Aetherphone issues](https://github.com/XeldarAlz/FFXIV-Aetherphone/issues) and say which beta
you are on.
